Car Buy and Sell System

A web application for buying and selling cars, featuring admin, user, and seller roles. Developed using HTML, CSS, JavaScript, and PHP.

Key Features
- User Roles: Admin, Seller, and Buyer (User) accounts.
- Car Listings: Ability to post, view, and search for vehicles.
- Responsive Design: Built using HTML and CSS for better usability.
- Database Integration: Integrated with MySQL using PHP.

Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- XAMPP (Local Server)
